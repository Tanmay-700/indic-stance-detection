1. Executive Summary & Workflow

The objective of this phase was to develop, train, evaluate, and diagnose models for detecting stance on climate change across Hindi and Bengali social media comments. The project was split across two core modeling paradigms:

  • Step 4 (Classical Machine Learning Baselines): High-dimensional sparse statistical modeling using a customized dual-level TF-IDF feature space (word n-grams and character subwords) evaluated on Complement Naive Bayes, Logistic Regression, Linear Support Vector Classifier, and Random Forest.
  • Step 5 (Contextual Transformer Fine-Tuning): Deep representation learning using Google MuRIL (Multilingual Representations for Indic Languages), featuring custom emoji vocabulary expansion, embedding matrix resizing, and GPU fine-tuning.

2. Step 4: Classical Machine Learning Baselines

2.1 The Underlying Challenges & Engineered Solutions

Before training classical classifiers, we had to address two critical domain-specific challenges inherent to Indic scripts:

  1. The Default Tokenizer Bug in Scikit-Learn: Scikit-Learn's default tokenization regular expression is (?u)\b\w\w+\b. In Devanagari and Bengali, Unicode word boundaries (\b) split vowel modifiers (matras) and consonant conjunct markers (virama / halant: ्, ্) from their base letters. Furthermore, this regex completely strips standalone emojis (such as 🌱, 🌍, 🙄, 🤡), which are crucial indicators of user stance. To resolve this, we implemented a custom regex tokenizer indic_tokenize() that preserves all matras, halants, Chandrabindu (ँ, ঁ), and complete emoji grapheme clusters, and set token_pattern=None.
  2. Dual-Level Feature Representation (Word + Character Subwords): Hindi and Bengali are morphologically rich and agglutinative languages. Using word tokens alone misses shared roots across dialectal inflections (e.g., काटने vs काटेंगे, or কাটা vs কাটলে). We built a FeatureUnion combining word-level n-grams (1–2) and character boundary n-grams (2–4). This expanded the representation to 40,260 features with strict zero data leakage (fitted exclusively on the training split).

2.2 Complete Code for Step 4 Feature Engineering & Baseline Models

The following complete, self-contained Python code reflects the exact implementation from src/baselines.py: 

import re
import numpy as np
import pandas as pd
from sklearn.pipeline import FeatureUnion
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.naive_bayes import ComplementNB
from sklearn.linear_model import LogisticRegression
from sklearn.svm import LinearSVC
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import classification_report, f1_score, accuracy_score

# --------------------------------------------------------------------------
# 1. Custom Indic Tokenizer (Preserves Matras, Halants, and Emojis)
# --------------------------------------------------------------------------
INDIC_TOKEN_PATTERN = re.compile(
    r'[\u0900-\u097F]+|'            # Devanagari (Hindi) words with matras & halants
    r'[\u0980-\u09FF]+|'            # Bengali words with matras & halants
    r'[\U00010000-\U0010ffff]|'     # 4-byte SMP Emojis (🌱, 🌍, 🤡, etc.)
    r'[\u2600-\u27bf]|'             # Standard Unicode symbols (⚡, ☀️, etc.)
    r'[0-9]+|'                      # Numerals
    r'[^\s\w]'                      # Punctuation (। , ! ?)
)

def indic_tokenize(text):
    if not isinstance(text, str):
        return []
    return INDIC_TOKEN_PATTERN.findall(text)

# --------------------------------------------------------------------------
# 2. Dual-Level TF-IDF FeatureUnion (Word 1-2 + Char Subwords 2-4)
# --------------------------------------------------------------------------
word_vec = TfidfVectorizer(
    tokenizer=indic_tokenize,
    token_pattern=None,
    ngram_range=(1, 2),
    min_df=2,
    sublinear_tf=True
)

char_vec = TfidfVectorizer(
    analyzer="char_wb",
    ngram_range=(2, 4),
    min_df=2,
    sublinear_tf=True
)

tfidf_union = FeatureUnion([
    ("word", word_vec),
    ("char", char_vec)
])

# Load preprocessed splits
train_df = pd.read_csv("data/processed/train.csv")
val_df = pd.read_csv("data/processed/val.csv")
test_df = pd.read_csv("data/processed/test.csv")

# Strict Zero Data Leakage: Fit strictly on Train
X_train = tfidf_union.fit_transform(train_df["cleaned_text"])
y_train = train_df["stance"].values

X_val = tfidf_union.transform(val_df["cleaned_text"])
y_val = val_df["stance"].values

X_test = tfidf_union.transform(test_df["cleaned_text"])
y_test = test_df["stance"].values

print(f"Feature Space Dimensions: {X_train.shape[1]:,d} features")

# --------------------------------------------------------------------------
# 3. Model 1: Complement Naive Bayes (Champion Baseline)
# --------------------------------------------------------------------------
cnb_model = ComplementNB(alpha=0.5, norm=True)
cnb_model.fit(X_train, y_train)

# --------------------------------------------------------------------------
# 4. Model 2: Logistic Regression (Balanced L2 Regularization)
# --------------------------------------------------------------------------
lr_model = LogisticRegression(
    C=1.0, 
    max_iter=1000, 
    class_weight="balanced", 
    random_state=42
)
lr_model.fit(X_train, y_train)

# --------------------------------------------------------------------------
# 5. Model 3: Linear Support Vector Classifier (LinearSVC)
# --------------------------------------------------------------------------
svc_model = LinearSVC(
    C=1.0, 
    class_weight="balanced", 
    random_state=42
)
svc_model.fit(X_train, y_train)

# --------------------------------------------------------------------------
# 6. Model 4: Random Forest (100 Trees Ensemble)
# --------------------------------------------------------------------------
rf_model = RandomForestClassifier(
    n_estimators=100, 
    class_weight="balanced", 
    random_state=42, 
    n_jobs=-1
)
rf_model.fit(X_train, y_train)

# --------------------------------------------------------------------------
# 7. Evaluation Function
# --------------------------------------------------------------------------
models = {
    "ComplementNB": cnb_model,
    "LogisticRegression": lr_model,
    "LinearSVC": svc_model,
    "RandomForest": rf_model
}

for name, clf in models.items():
    preds = clf.predict(X_test)
    acc = accuracy_score(y_test, preds)
    macro_f1 = f1_score(y_test, preds, average="macro")
    print(f"{name:20s} | Test Accuracy: {acc*100:.2f}% | Test Macro F1: {macro_f1:.4f}")

3. Step 5: Contextual Transformer Fine-Tuning (Google MuRIL)

3.1 Background on Google MuRIL

Google MuRIL (google/muril-base-cased) is a BERT-based transformer model explicitly designed for Indic natural language processing. It is pretrained on 17 Indic languages (including Hindi and Bengali) and English, using monolingual corpora, translated parallel pairs, and transliterated pairs. Unlike general multilingual BERT (mBERT), MuRIL is specifically optimized to bridge the lexical gap between related Indian languages.

3.2 The MuRIL [UNK] Emoji Problem & Vocabulary Expansion

During our initial inspection of MuRIL's WordPiece tokenizer, we uncovered a significant issue:

The Problem: While MuRIL's tokenizer contains 197,285 tokens covering native Indic syllables, it contains zero modern emojis. Standard tokenization converted emojis such as 🌱, 🌍, 🙄, and 🤡 into token ID 1 (the unknown token [UNK]). This meant the deep neural network was completely blind to emoji-based sentiment and sarcasm.

Our Engineered Solution:

  1. We wrote an emoji extraction function that scraped all unique emoji sequences from our Hindi and Bengali splits.
  2. We invoked tokenizer.add_tokens(unique_emojis), registering each distinct emoji as an official vocabulary token.
  3. We invoked model.resize_token_embeddings(len(tokenizer)), expanding the model's input embedding matrix from 197,285 to 197,297 rows. This enabled the model to initialize and learn dedicated 768-dimensional contextual vectors for stance-bearing emojis.

3.3 Complete Code for Step 5 (PyTorch & Transformers Engine)

The following complete Python code represents the exact training and evaluation pipeline from src/transformers_train.py and our Google Colab GPU notebook: 

import re
import os
import torch
import numpy as np
import pandas as pd
from torch.utils.data import Dataset, DataLoader
from transformers import (
    AutoTokenizer,
    AutoModelForSequenceClassification,
    get_linear_schedule_with_warmup
)
from sklearn.metrics import classification_report, accuracy_score, f1_score

# --------------------------------------------------------------------------
# 1. Configuration & Label Mapping
# --------------------------------------------------------------------------
MODEL_NAME = "google/muril-base-cased"
TARGET_CLASSES = ["AGAINST", "FAVOUR", "NONE"]
LABEL2ID = {label: idx for idx, label in enumerate(TARGET_CLASSES)}
ID2LABEL = {idx: label for idx, label in enumerate(TARGET_CLASSES)}
DEVICE = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# --------------------------------------------------------------------------
# 2. PyTorch Dataset Wrapper
# --------------------------------------------------------------------------
class IndicStanceDataset(Dataset):
    def __init__(self, texts, labels=None, tokenizer=None, max_length=128):
        self.texts = list(texts)
        self.labels = [LABEL2ID[l] for l in labels] if labels is not None else None
        self.tokenizer = tokenizer
        self.max_length = max_length

    def __len__(self):
        return len(self.texts)

    def __getitem__(self, idx):
        text = str(self.texts[idx])
        encoding = self.tokenizer(
            text,
            truncation=True,
            padding="max_length",
            max_length=self.max_length,
            return_tensors="pt"
        )
        item = {
            "input_ids": encoding["input_ids"].squeeze(0),
            "attention_mask": encoding["attention_mask"].squeeze(0)
        }
        if self.labels is not None:
            item["labels"] = torch.tensor(self.labels[idx], dtype=torch.long)
        return item

# --------------------------------------------------------------------------
# 3. Emoji Vocabulary Expansion Routine
# --------------------------------------------------------------------------
def expand_tokenizer_vocab(tokenizer, model, texts):
    emoji_regex = re.compile(r'[\U00010000-\U0010ffff\u2600-\u27bf]')
    discovered_emojis = sorted(list(set(emoji_regex.findall(" ".join(texts)))))
    num_added = tokenizer.add_tokens(discovered_emojis)
    print(f"Added {num_added} unique emojis to MuRIL tokenizer!")
    if num_added > 0:
        model.resize_token_embeddings(len(tokenizer))
        print("Resized model token embeddings successfully.")
    return tokenizer, model

# --------------------------------------------------------------------------
# 4. Training Loop with AdamW & Linear Warmup
# --------------------------------------------------------------------------
def train_muril_model(epochs=3, batch_size=16, lr=2e-5):
    # Load data
    train_df = pd.read_csv("data/processed/train.csv")
    val_df = pd.read_csv("data/processed/val.csv")
    test_df = pd.read_csv("data/processed/test.csv")

    # Initialize Tokenizer and Model
    tokenizer = AutoTokenizer.from_pretrained(MODEL_NAME)
    model = AutoModelForSequenceClassification.from_pretrained(
        MODEL_NAME, 
        num_labels=3,
        id2label=ID2LABEL,
        label2id=LABEL2ID
    )

    # Expand Vocabulary
    all_texts = train_df["cleaned_text"].tolist() + test_df["cleaned_text"].tolist()
    tokenizer, model = expand_tokenizer_vocab(tokenizer, model, all_texts)
    model.to(DEVICE)

    # Prepare DataLoaders
    train_ds = IndicStanceDataset(train_df["cleaned_text"], train_df["stance"], tokenizer)
    val_ds = IndicStanceDataset(val_df["cleaned_text"], val_df["stance"], tokenizer)
    test_ds = IndicStanceDataset(test_df["cleaned_text"], test_df["stance"], tokenizer)

    train_loader = DataLoader(train_ds, batch_size=batch_size, shuffle=True)
    val_loader = DataLoader(val_ds, batch_size=batch_size, shuffle=False)
    test_loader = DataLoader(test_ds, batch_size=batch_size, shuffle=False)

    # Optimizer and Scheduler
    optimizer = torch.optim.AdamW(model.parameters(), lr=lr, weight_decay=0.01)
    total_steps = len(train_loader) * epochs
    scheduler = get_linear_schedule_with_warmup(
        optimizer, 
        num_warmup_steps=int(total_steps * 0.1), 
        num_training_steps=total_steps
    )

    best_val_f1 = -1.0
    output_dir = "models/transformer_muril"
    os.makedirs(output_dir, exist_ok=True)

    for epoch in range(1, epochs + 1):
        model.train()
        total_train_loss = 0.0

        for batch in train_loader:
            optimizer.zero_grad()
            input_ids = batch["input_ids"].to(DEVICE)
            attention_mask = batch["attention_mask"].to(DEVICE)
            labels = batch["labels"].to(DEVICE)

            outputs = model(input_ids=input_ids, attention_mask=attention_mask, labels=labels)
            loss = outputs.loss
            loss.backward()

            torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
            optimizer.step()
            scheduler.step()

            total_train_loss += loss.item() * len(input_ids)

        avg_loss = total_train_loss / len(train_ds)

        # Validation Evaluation
        model.eval()
        val_preds, val_labels = [], []
        with torch.no_grad():
            for batch in val_loader:
                input_ids = batch["input_ids"].to(DEVICE)
                attention_mask = batch["attention_mask"].to(DEVICE)
                labels = batch["labels"].to(DEVICE)

                logits = model(input_ids=input_ids, attention_mask=attention_mask).logits
                preds = torch.argmax(logits, dim=-1).cpu().numpy()
                val_preds.extend(preds)
                val_labels.extend(labels.cpu().numpy())

        val_f1 = f1_score(val_labels, val_preds, average="macro")
        print(f"Epoch {epoch}/{epochs} | Train Loss: {avg_loss:.4f} | Val Macro F1: {val_f1:.4f}")

        if val_f1 > best_val_f1:
            best_val_f1 = val_f1
            model.save_pretrained(output_dir)
            tokenizer.save_pretrained(output_dir)
            print(f"  -> Best model saved to {output_dir}")

    # ----------------------------------------------------------------------
    # Final Test Set Evaluation
    # ----------------------------------------------------------------------
    best_model = AutoModelForSequenceClassification.from_pretrained(output_dir).to(DEVICE)
    best_model.eval()
    test_preds, test_labels = [], []

    with torch.no_grad():
        for batch in test_loader:
            input_ids = batch["input_ids"].to(DEVICE)
            attention_mask = batch["attention_mask"].to(DEVICE)
            labels = batch["labels"].to(DEVICE)

            logits = best_model(input_ids=input_ids, attention_mask=attention_mask).logits
            preds = torch.argmax(logits, dim=-1).cpu().numpy()
            test_preds.extend(preds)
            test_labels.extend(labels.cpu().numpy())

    print("\n--- MuRIL Final Test Classification Report ---")
    print(classification_report(test_labels, test_preds, target_names=TARGET_CLASSES, digits=4))

5. Conclusion & Transition to Step 6

The comparative findings from Step 4 and Step 5 demonstrated that neither model is flawless in isolation:

  • Step 4 (Classical ML) provides strong, non-distractible lexical n-gram anchoring that prevents false positives when negation or minimizing clauses accompany strong environmental nouns.
  • Step 5 (Google MuRIL) provides deep semantic generalization, cross-lingual transferability between Hindi and Bengali scripts, and contextual understanding of sarcasm and nuanced emotion.

This empirical evidence proved that combining both models via a Soft-Voting Probability Ensemble ($w_{\text{MuRIL}} \cdot P_{\text{MuRIL}} + w_{\text{Classical}} \cdot P_{\text{Classical}}$) produces the most robust stance classification system.
