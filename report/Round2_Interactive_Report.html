1 Dataset — Which Dataset & Why?

Motivation

While English climate-stance benchmarks exist (SemEval-2016 Task 6, VAST), no standardised dataset targets Hindi (~600 M speakers) or Bengali (~300 M speakers) — the two largest South Asian languages facing recurring heatwaves, glacier outbursts, and cyclones. We fill this gap with a custom curated corpus.

Target Claim

"Climate change and global warming is a serious concern."
Every comment is labelled relative to this claim: FAVOUR (agrees) · AGAINST (denies/minimises) · NONE (neutral/unrelated).

Corpus Construction

  • 440 master seeds across 11 subcategories (deforestation, glacier retreat, renewable energy, floods, emissions, carbon taxes, conspiracy theories, neutral enquiries, etc.)
  • 220 Hindi seeds + 220 Bengali seeds
  • Each seed expanded ×7 via paraphrase, emoji injection, noise, and sarcasm templates → 3,200 visible + 320 hidden test = 3,520 total

Multi-Tier Noise Engine

  • 35% Clean: Standard grammar with Danda (।) punctuation
  • 50% Light Noise: Matra elongation ("बहुत ज्यादााा"), emoji clusters (🌍🌱🤡🙄🔥), punctuation spam (!!??)
  • 15% Heavy Noise: Sarcastic negation, regional slang variants, code-mixed fragments

Custom Indic Preprocessing (src/preprocessing.py)

  • Unicode NFC Normalisation: Canonicalises decomposed matras into unified codepoints
  • Zero-Width Sanitisation: Strips ZWJ (‍) & ZWNJ (‌) injected by mobile keyboards
  • Emoji Preservation: Pads 4-byte SMP emojis with whitespace to prevent token fusion
  • Danda Normalisation: Converts ASCII pipe | → authentic Devanagari danda ।
  • Selective De-elongation: Collapses matra repetitions while preserving Chandrabindu (ँ, ঁ)
def clean_indic_text(text):
    """Unicode-aware preprocessing for Hindi & Bengali."""
    text = unicodedata.normalize('NFC', text)
    text = text.replace('\u200c','').replace('\u200d','')
    text = re.sub(r'[\U00010000-\U0010ffff]', lambda m: f' {m.group()} ', text)
    text = text.replace('|', '।')
    return text.strip()

Dual-Level TF-IDF Feature Union (src/baselines.py)

Key Idea: Default scikit-learn tokenizers strip Indic matras and delete emojis. We use a custom indic_tokenize() inside a FeatureUnion that merges:
Stream 1: Word n-grams (1–2) → 25,000 features
Stream 2: Subword char n-grams (2–4, char_wb) → 25,000 features
Total: 40,260 sparse features (leak-free, fitted only on Train)

Google MuRIL — Multilingual Representations for Indian Languages

  • BERT architecture pretrained on 17 Indian languages (110M parameters)
  • Emoji Vocabulary Expansion: Added 12 missing social emojis → resized embedding from 197,285 → 197,297 tokens
  • Fine-tuned on Google Colab Tesla T4 GPU (AdamW, lr=2e-5, linear warmup, 3 epochs)
  • Model weights: ~950 MB safetensors in models/transformer_muril/
Why MuRIL over mBERT? MuRIL is explicitly pretrained on transliterated and native-script Indian language data, giving it superior subword coverage for Devanagari and Bengali compared to generic multilingual BERT.

MuRIL (70%) + TF-IDF LR (30%)

The hybrid approach leverages MuRIL's deep contextual reasoning for sarcasm and implicit sentiment, while Logistic Regression anchors lexical markers and emoji patterns that the transformer may underweight.

4 Experimental Results & Performance Analysis

Primary Metric: Macro-Averaged F1

Why Macro F1? Plain accuracy hides failures on minority classes. If a model predicts FAVOUR for everything in a 70/30 split, it gets 70% accuracy but 0% recall on AGAINST. Macro F1 averages per-class F1 equally, ensuring climate denial detection is never masked.

6 Challenges Encountered & Solutions

Windows cp1252 Terminal Crashes
Python threw UnicodeEncodeError printing Indic characters.
Fix: sys.stdout.reconfigure(encoding="utf-8") at script entry.
Pandas NONE → NaN Corruption
pd.read_csv() silently converted stance label "NONE" into NaN floats.
Fix: keep_default_na=False on every read_csv() call.
MuRIL Emoji Vocabulary Collapse
Base MuRIL mapped social emojis to [UNK], destroying sentiment cues.
Fix: Expanded vocabulary by +12 emoji tokens, resized embedding layer to 197,297 rows.
Scikit-Learn Regex Strips Indic Matras
Default token_pattern breaks conjunct characters.
Fix: Set token_pattern=None, passed custom indic_tokenize() as the tokenizer.
