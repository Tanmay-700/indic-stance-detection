Abstract

Stance detection in low-resource, morphologically complex South Asian languages remains an open challenge due to non-standard orthography, aggressive matra elongations, code-mixing, and pervasive rhetorical irony. In this work, we present an end-to-end computational framework for detecting stances toward climate change across Hindi (Devanagari) and Bengali (Bangla). We curate a balanced 3,520-sample corpus (3,200 visible, 320 hidden) with a three-tier noise engine mimicking real-world social media dynamics. We introduce an Indic Unicode normalization and custom subword tokenization pipeline with Chandrabindu and emoji preservation, a 40,260-dimensional dual TF-IDF FeatureUnion, four classical machine learning baselines, and a fine-tuned Google MuRIL transformer with an expanded emoji vocabulary. Our proposed Full Hybrid Soft-Voting Ensemble (MuRIL 70% + Logistic Regression 30%) achieves a state-of-the-art 0.9844 Macro F1, solving semantic minimization and sarcasm blind spots where standalone transformer models fail. Finally, cross-lingual zero-shot transfer demonstrates a 0.6684 Macro F1 without target-language training, which closes to 0.9750 under joint bilingual supervision.

Index Terms—Indic NLP, Stance Detection, Climate Change Discourse, Google MuRIL, Hybrid Ensembles, Unicode Normalization, Cross-Lingual Zero-Shot Transfer, Macro F1.

I. Dataset Curation & Corpus Statistics Corpus Size: 3,520 Samples

While standardized English benchmarks such as SemEval-2016 Task 6 and VAST have catalyzed stance detection research, high-vulnerability linguistic regions like South Asia remain critically underrepresented. Hindi and Bengali account for over 900 million speakers, yet lack standardized, fine-grained stance corpora evaluating climate change discourse.

A. 11 Subcategories & Seed Expansion

To prevent topical bias, we engineered 440 master seed statements (220 Hindi, 220 Bengali) spanning 11 realistic thematic subcategories: deforestation, Himalayan glacier retreat, renewable solar/wind infrastructure, agricultural droughts, coastal cyclones, vehicular emissions, carbon tax legislation, climate denial conspiracy theories, seasonal weather observations, religious inquiries, and unrelated conversational talk.

B. Multi-Tier Social Media Noise Engine

Standard news corpora fail to represent informal social feeds. We injected controlled linguistic noise to mirror real-world social networks:

  • 35% Clean Tier: Standard grammar, formal vocabulary, authentic danda (।) punctuation.
  • 50% Light Noise Tier: Matra elongations (e.g., "बहुत ज्यादााा"), punctuation clusters (!!??), and SMP emoji clusters (🌱, 🌍, 🤡, 🙄, 🔥).
  • 15% Heavy Noise Tier: Colloquial slang, regional orthographical shifts, sarcastic negation, and code-mixed lexical tokens.

II. Methodology & System Architecture Step 1 to Step 6

Our technical pipeline implements a 6-phase modular workflow avoiding common Indic NLP pitfalls such as character fragmentation, token fusion, and leakage.

A. Unicode Normalization & Custom Tokenization

Standard Python regular expressions split Indic conjuncts and discard matras. We developed clean_indic_text() and indic_tokenize() in src/preprocessing.py:

  • Unicode NFC Normalization: Merges decomposed vowel modifiers into atomic codepoints.
  • Zero-Width Stripping: Eliminates hidden ZWJ (\u200d) and ZWNJ (\u200c) inserted by mobile keyboards.
  • SMP Emoji Preservation: Pads 4-byte emojis with whitespace boundaries so that emotional icons (e.g., 🤡, 🙄) are preserved as standalone tokens.
  • Punctuation & Chandrabindu Safety: Replaces pipe symbols with danda (।) while strictly protecting Chandrabindu (ँ, ঁ).
src/preprocessing.py — Unicode Normalizer 
import re, unicodedata

def clean_indic_text(text: str) -> str:
    text = unicodedata.normalize("NFC", str(text))
    text = text.replace("\u200b", "").replace("\u200c", "").replace("\u200d", "")
    text = re.sub(r"[\U00010000-\U0010ffff]", lambda m: f" {m.group(0)} ", text)
    text = text.replace("|", "।")
    text = re.sub(r"[\u0902\u0982]{2,}", lambda m: m.group(0)[0], text)
    return re.sub(r"\s+", " ", text).strip()

B. Dual TF-IDF Feature Engineering (40,260 Dimensions)

In src/baselines.py, we constructed a FeatureUnion merging word n-grams (1–2, 25,000 max features) and character n-grams inside word boundaries (char_wb, 2–4, 25,000 max features). This yields a leak-free 40,260-dimensional sparse feature space fitted strictly on training data.

C. Google MuRIL Transformer Fine-Tuning

We leveraged Google MuRIL (Multilingual Representations for Indian Languages, 110M parameters), fine-tuned on a Tesla T4 GPU (AdamW, learning rate $2 \times 10^{-5}$, linear warmup, 3 epochs). Because off-the-shelf MuRIL collapses social emojis into [UNK], we expanded the vocabulary with 12 missing emojis and resized the embedding matrix from 197,285 to 197,297 rows.

D. Full Hybrid Soft-Voting Ensemble Formulation

Standalone transformer representations sometimes underweight overt lexical markers, whereas n-gram models miss deep rhetorical shifts. We fuse their posterior probabilities via weighted soft-voting:

$$P_{\text{Hybrid}}(y = c \mid x) = w_{\text{MuRIL}} \cdot P_{\text{MuRIL}}(y = c \mid x) + (1 - w_{\text{MuRIL}}) \cdot P_{\text{LR}}(y = c \mid x)$$

Grid search on the validation set identified the optimal balance at $w_{\text{MuRIL}} = 0.70$ and $w_{\text{LR}} = 0.30$.

III. Experimental Results & Performance Analysis Primary Metric: Macro F1

In stance detection, accuracy is notoriously deceptive. A model that blindly predicts the majority class can attain high accuracy while failing completely on minority stances. Therefore, we adopt Macro-Averaged F1 as our primary benchmark metric:

$$\text{Macro F1} = \frac{1}{|C|} \sum_{c \in C} \frac{2 \cdot P_c \cdot R_c}{P_c + R_c}, \quad C = \{\text{FAVOUR}, \text{AGAINST}, \text{NONE}\}$$

VI. Key Challenges Encountered & Engineering Mitigations Diagnostics

1. Windows Console `cp1252` Encoding Crash

When printing Devanagari or Bengali tokens to PowerShell / CMD, Python threw fatal UnicodeEncodeError due to legacy Windows OEM codepages.

Engineering Mitigation: Added sys.stdout.reconfigure(encoding="utf-8") at the top of all executable scripts and verified UTF-8 streams globally.
2. Pandas `NONE` Class Label Conversion into NaN

Default pd.read_csv() interprets string "NONE" as missing data (NaN), turning 1,065 valid neutral labels into float NaNs and crashing scikit-learn metrics.

Engineering Mitigation: Enforced keep_default_na=False across all data loaders in src/, notebooks/, and app.py.
3. MuRIL Vocabulary Collapse on Social Emojis

Pretrained MuRIL tokenizer collapsed crucial sentiment emojis (e.g., 🤡, 🙄, 🌱) into [UNK] tokens, destroying critical sarcasm signals.

Engineering Mitigation: Expanded the tokenizer vocabulary with 12 missing emojis and called model.resize_token_embeddings(197297) prior to fine-tuning.
4. Scikit-Learn Regex Stripping Indic Matras

Default scikit-learn token_pattern=r"(?u)\b\w\w+\b" silently stripped Indic vowel modifiers and broke compound conjuncts.

Engineering Mitigation: Set token_pattern=None and supplied custom tokenizer=indic_tokenize inside TfidfVectorizer.
