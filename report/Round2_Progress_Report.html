1 Dataset Description, Curation & Statistics

Motivation & Need: While climate discourse benchmarks (SemEval-2016 Task 6, VAST) exist for English, low-resource Indic languages lack standardized stance datasets despite South Asia suffering recurring heatwaves, glacier outbursts, and coastal cyclones. We target Hindi (Devanagari, ~600M speakers) and Bengali (Bangla script, ~300M speakers).

Corpus Construction: Curated 3,520 comments (3,200 visible + 320 hidden test) spanning 11 realistic subcategories: deforestation, glacier retreat, renewable energy, floods, vehicular emissions, carbon taxes, climate denial conspiracy theories, and neutral inquiries.

Multi-Tier Noise Engine: Social media text diverges sharply from news corpora. We designed a realistic 3-tier noise generator:

  • 35% Clean: Standard grammatical syntax with danda (।) punctuation.
  • 50% Light Noise: Matra elongations ("बहुत ज्यादााा"), punctuation clusters (!!??), and sentiment emojis (🌍, 🌱, 🤡, 🙄, 🔥).
  • 15% Heavy Noise: Sarcastic negation, colloquial slang, and regional spelling variants.

2 Current Methodology, Models & Technical Workflow

Our pipeline implements an end-to-end, multi-stage architecture transitioning from linguistic preprocessing to dual-level feature engineering, transformer fine-tuning, and soft-voting ensemble hybridization:

Phase 1 & 2: Preprocessing & Normalization (src/preprocessing.py)
  • Unicode NFC Normalization: Canonicalizes decomposed matras into single unified codepoints to prevent feature fragmentation.
  • Zero-Width & Punctuation Sanitization: Strips mobile zero-width joiners/non-joiners (​, ‌, ‍); normalizes ASCII pipes | to authentic Indic dandas (।); preserves Chandrabindu (ँ, ঁ).
  • Emoji Preservation: Isolates 4-byte Supplementary Multilingual Plane (SMP) emojis with whitespace padding to prevent token fusion.
Phase 3: Dual-Level TF-IDF Feature Engineering (src/baselines.py)

Default tokenizers delete emojis and break Indic conjuncts. We authored custom indic_tokenize() embedded inside a FeatureUnion merging word n-grams (1–2, 25k features) with subword character n-grams inside word boundaries (char_wb, 2–4, 25k features), generating a leak-free 40,260-dimensional feature space fitted strictly on Train.

Phase 4 & 5: Model Zoo — Classical Baselines & Google MuRIL Transformer
Classical ML Baselines:
  • Complement Naive Bayes (CNB): Evaluates complement frequencies; robust to subtle class skew.
  • Logistic Regression (LR): L2-regularized with class-weighted cost balancing.
  • Linear SVC: Max-margin hyperplane with linear kernel.
  • Random Forest: 200 estimators for non-linear bagging.
Google MuRIL Transformer (src/transformers_train.py):
  • BERT architecture pretrained on 17 Indic languages (110M params).
  • Vocab Expansion: Added 12 missing emojis to tokenizer; resized embedding layer from 197,285 to 197,297 rows.
  • Fine-tuned on Tesla T4 GPU (AdamW, lr=2e-5, linear warmup, 3 epochs).
Phase 6: Ensemble Soft-Voting & Hybridization (src/ensemble.py)

Aggregates probability distributions: (1) Classical Soft-Voting: LR (50%) + CNB (50%); (2) Full Hybrid Ensemble: MuRIL (70%) + LR (30%). MuRIL provides deep contextual reasoning, while Logistic Regression anchors lexical markers and emojis.

4 Key Challenges Encountered & Engineering Solutions

1. Windows CRT cp1252 Terminal Crashes: Python threw UnicodeEncodeError printing Indic characters. Fixed globally via sys.stdout.reconfigure(encoding="utf-8").
2. Pandas Label Corruption on NONE: pd.read_csv() converted stance "NONE" into NaN floats. Solved with keep_default_na=False across all scripts.
3. Pretrained MuRIL Emoji Vocabulary Collapse: Base MuRIL lacked social emojis, collapsing them into [UNK]. We expanded the vocabulary (+12 tokens) and resized the embedding table to 197,297 rows.
4. Scikit-Learn Regex Stripping Matras: Default word regex broke Indic conjuncts. Solved via custom regex with token_pattern=None.
